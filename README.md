# E-Commerce Website — Manual QA Testing

## 📌 Project Overview

This project demonstrates manual QA testing of an e-commerce web application.

The objective was to verify key application functionalities against defined requirements, execute test cases, identify potential defects, and maintain proper QA documentation.

## 🧪 Testing Scope

The following areas were tested:

- Login functionality
- Product details
- Add to Cart
- Remove from Cart
- Cart validation
- Checkout functionality
- Required field validation

## 🔍 Testing Types

- Functional Testing
- Positive Testing
- Negative Testing
- Boundary Value Analysis (BVA)
- Equivalence Partitioning
- Smoke Testing
- Sanity Testing
- Regression Testing
- Retesting
